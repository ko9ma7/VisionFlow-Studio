GETTING STARTED

작은 작업 하나부터 시작하세요.

먼저 이미지 한 개를 찾아 반응하는 작업을 만들어 봅니다. 대상 창과 탐지 위치를 확인한 뒤 실제 입력을 허용하세요.

현재 다운로드는 기존 배포 저장소의 VisionFlow Studio 2.7.1입니다. 새 공개 저장소의 릴리스·Pages 배포 검증은 진행 중입니다.

1. 설치하고 실행하기

기존 릴리스에서 Windows 패키지를 다운로드하고 새 폴더에 완전히 풉니다. Windows x64와 .NET 8 Desktop Runtime을 준비한 뒤 VisionFlowStudio.exe를 실행합니다.

2. 대상 창과 찾을 이미지 선택

자동화할 프로그램의 창을 열고 실행 화면에서 선택합니다. 새 작업 만들기에서 이미지 찾기 목적을 고른 뒤 생성한 작업의 상세 설정에서 찾을 이미지와 영역을 등록합니다.

3. 반응과 조건 연결

클릭, 키 입력, 대기 등 동작을 정합니다. 찾은 대상에 상대적인 좌표를 쓰면 창 이동 후에도 대상 위치를 기준으로 반응할 수 있습니다. 발견·미발견 분기와 반복 조건을 검토합니다.

4. 관찰 모드로 확인

실제 입력 전에 관찰 모드로 이미지가 올바르게 탐지되는지 확인합니다. 탐지 박스와 입력 좌표가 의도한 위치인지 보세요. 대상 창, 해상도, DPI나 입력 방식이 달라졌다면 다시 확인하세요.

5. 실행하고 저장

대상을 확인했다면 실제 입력을 허용하고 실행합니다. 일시정지는 현재 동작이 끝나는 안전 경계에서 대기하며, 중지는 입력 정리 후 종료합니다. 프로젝트와 사용한 이미지·모델을 함께 보관하세요.

인증과 업데이트

서명된 인증 채널을 확인합니다. 오프라인에서는 검증된 캐시나 동봉된 채널의 정책이 적용됩니다. 실패 이유는 화면에 표시되며 로컬 진단을 사용할 수 있습니다. GitHub 비밀번호나 토큰을 프로그램에 입력하지 않습니다.

기존 업데이트와 인증 URL은 호환을 위해 유지합니다. 업데이트 전에는 프로젝트를 백업하고 서명 또는 해시 검사가 실패한 파일은 사용하지 마세요.

문제가 생겼다면

대상 창이 열려 있는지, 이미지와 모델 파일이 존재하는지 먼저 확인합니다. 로그와 로컬 진단에서 실패 이유를 확인하고, 문제를 보고할 때 개인 화면·API 키·설정 내용을 공개하지 마세요.
