확장을 위한 공개 계약

현재 SDK는 API1 미리보기 계약입니다. 개선 중인 Studio는 신뢰한 DLL을 이 세션에 명시적으로 불러오는 host를 제공합니다. 공개 배포본의 제공 여부는 실제 Release에서 확인하세요. 프로젝트에서 DLL을 자동 실행하지 않습니다.

Core 구현을 공개하지 않고 작업, 화면 가져오기, 인식, 입력과 OCR 제공자의 경계를 정의합니다. 공개 SDK는 비공개 Core나 OpenCV를 참조하지 않습니다.

인터페이스

  • IVisionFlowAction — 작업 실행 및 구조화된 결과
  • ICaptureProvider — 화면 프레임 제공
  • IVisionProvider, IOcrProvider — 탐지 및 글자 결과
  • IInputProvider — 입력 서비스 계약
  • IExtension — 확장 정보와 제공 기능

예제 빌드

.NET 8 SDK 이상으로 공개 저장소의 HelloAction을 빌드합니다. 이 예제는 인사 문자열을 반환하며 실제 키·마우스 입력을 수행하지 않습니다.

dotnet build examples/HelloAction/HelloAction.csproj -c Release

SDK 소스와 계약 안내 · HelloAction 예제

값과 취소

텍스트, 숫자, Boolean, 좌표, 영역과 탐지 결과를 타입으로 구분합니다. 실행 문맥은 취소 토큰을 전달하며 제공되지 않은 입력 서비스에 접근하면 명확한 오류를 반환합니다.
