# 개인 환경과 사용 권한

VisionFlow Studio의 **도구 → 개인 환경·사용 권한**에서 이 Windows 사용자에게 적용할 설정을 저장합니다. 프로젝트 파일이나 다른 사용자의 설정은 바뀌지 않습니다.

각 기능은 다음 중 하나를 선택합니다.

| 선택 | 동작 |
|---|---|
| 실행할 때 확인 | 기존처럼 프로젝트 실행 전에 필요한 권한을 확인합니다. |
| 항상 허용 | 사용 책임을 확인하고 저장하면 다음 실행에서도 해당 권한을 다시 묻지 않습니다. |
| 차단 | 실제 실행과 Debug에서 해당 기능을 사용할 수 없습니다. 연결된 다른 Flow에도 적용됩니다. |

관찰 모드는 실제 입력·프로그램 제어·AI 전송을 실행하지 않습니다. 확장은 관찰 모드에도 코드를 실행할 수 있으므로 확장 실행과 화면 제공의 차단은 유지됩니다. 확장을 허용하더라도 파일을 불러올 때의 개별 신뢰 확인은 필요합니다.

**Interception 입력**은 선택 기능입니다. 직접 준비한 x64 DLL의 로컬 경로를 입력하거나 파일을 선택하고, 출처와 사용 조건을 확인한 뒤 저장합니다. DLL은 앱과 같은 PC 권한으로 실행될 수 있습니다. 앱은 드라이버를 자동 설치하지 않으며 파일을 지정하는 것만으로 Windows 권한이나 라이선스가 생기지 않습니다.

DLL 경로는 앱을 다시 시작하면 적용됩니다. 저장할 때 확인한 SHA-256과 파일이 다르면 사용을 멈추며, 설정에서 파일을 다시 확인하고 저장해야 합니다. 경로를 비워 두면 기존 자동 검색을 사용합니다. DLL·드라이버가 없어도 기본 기능을 사용할 수 있으며, 드라이버가 필요한 기능은 준비 상태를 확인합니다.

저장 실패는 창에 표시되며 취소는 기존 설정을 보존합니다. 설정은 사용자 로컬 앱 데이터 폴더의 `VisionFlowStudio/user-environment.json`에 원자적으로 저장하고 이전 파일을 `.bak`으로 남깁니다. 손상된 설정은 조용히 허용으로 바꾸지 않으며 이 창에서 확인하고 다시 저장합니다.

AI 키·모델·메모리 프로필 등은 기존 설정 화면에서 관리합니다. 제품 인증과 업데이트 서명 검증은 계속 적용됩니다. 배포용 개인 서명 키는 일반 사용자 설정과 배포 패키지에 포함하지 않습니다.
