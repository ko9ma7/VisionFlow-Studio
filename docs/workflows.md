# 작업과 실행

작업은 화면에서 확인할 조건과 실행할 동작을 묶습니다. 작업 목록의 순서, 폴더의 조건, 발견·미발견 분기로 흐름을 구성할 수 있습니다. 시각 편집에서는 노드의 위치와 흐름을 확인합니다.

현재 사용 가능한 인식 기능에는 이미지 매칭, OCR, YOLO 객체 찾기, AOI 검사, 시각 사전과 동일 대상 추적이 있습니다. 마우스 클릭·드래그·스크롤·키·문자 입력과 반복·대기·분기 설정을 연결할 수 있습니다. OCR 데이터나 YOLO 모델은 해당 목적을 사용하는 경우에 필요합니다.

찾은 대상에 상대적인 좌표를 사용하면 창이 움직여도 같은 대상 위치를 기준으로 동작할 수 있습니다. 실제 입력 전에는 관찰 모드에서 탐지와 좌표를 확인하세요. 대상 창을 바꿨다면 캡처 영역과 입력 모드를 다시 확인하세요.

실행 중 창 핸들이 바뀌거나 캡처에 실패하면 실행 로그와 대상 상태를 확인합니다. 최소화된 창, 비활성 입력, 다중 모니터와 DPI 변경은 캡처·입력 방식과 대상 프로그램에 따라 결과가 달라질 수 있습니다. 화면에 표시된 결과를 기준으로 확인해야 합니다.

변수, 브레이크포인트, 확장 DLL 호스트와 자동 인식 방식 선택은 개발 중이며 현재 배포본의 기능으로 소개하지 않습니다.
