# 작업과 실행

## 이미지 없이 입력하거나 찾은 위치에서 키 누르기

- 작업 만들기에서 **이미지 없이 입력**을 고르면 키 누르기·마우스 이동·클릭을 바로 등록합니다. 기본 키는 Enter입니다.
- **이미지를 찾아 동작하기 → 찾은 위치로 이동 후 키 누르기**를 고르면 발견 위치로 이동한 다음 선택한 키를 보냅니다. 숫자 키패드의 숫자와 키보드 윗줄의 숫자를 구별합니다.
- 실행 창을 좁히면 도구 버튼이 다음 줄로 이동합니다.

## 2.9.0에서 그림을 찾은 뒤 할 일 고르기

| 하고 싶은 일 | 화면에서 고를 항목 |
|---|---|
| 그림 중심 반복 클릭 | **이미지 클릭 추가**에서 그림을 저장하고 **반복 실행** |
| Enter만 보내기 | **새 작업 만들기 → 이미지를 찾아 동작하기 → 키 누르기**. 다른 키는 **키 변경**에서 지정 |
| 클릭 후 키 보내기 | 첫 동작으로 **좌클릭**, **동작 추가 → 키 누르기**로 다음 입력 지정 |
| 로딩 표시가 사라지면 계속하기 | **이미지가 사라질 때까지 기다리기**에서 최대 대기 시간 지정 |

**찾기만 시험**은 위치를 보여줍니다. **저장 후 이 단계 실행**은 설정한 클릭이나 키를 실제 대상에 보냅니다. 미니 실행 창에서는 현재 단계를 보고 일시정지·재개·중지하거나 편집기로 돌아갈 수 있습니다.

작업은 화면에서 확인할 조건과 실행할 동작을 묶습니다. 작업 목록의 순서, 폴더의 조건, 발견·미발견 분기로 흐름을 구성할 수 있습니다. 시각 편집에서는 노드의 위치와 흐름을 확인합니다.

현재 사용 가능한 인식 기능에는 이미지 매칭, OCR, YOLO 객체 찾기, AOI 검사, 시각 사전과 동일 대상 추적이 있습니다. 마우스 클릭·드래그·스크롤·키·문자 입력과 반복·대기·분기 설정을 연결할 수 있습니다. OCR 데이터나 YOLO 모델은 해당 목적을 사용하는 경우에 필요합니다.

찾은 대상에 상대적인 좌표를 사용하면 창이 움직여도 같은 대상 위치를 기준으로 동작할 수 있습니다. 실제 입력 전에는 관찰 모드에서 탐지와 좌표를 확인하세요. 대상 창을 바꿨다면 캡처 영역과 입력 모드를 다시 확인하세요.

실행 중 창 핸들이 바뀌거나 캡처에 실패하면 실행 로그와 대상 상태를 확인합니다. 최소화된 창, 비활성 입력, 다중 모니터와 DPI 변경은 캡처·입력 방식과 대상 프로그램에 따라 결과가 달라질 수 있습니다. 화면에 표시된 결과를 기준으로 확인해야 합니다.

2.8.0 시험판에서 추가한 Recorder, 자식 Flow 입출력과 세션에서 신뢰한 SDK 확장 사용 범위는 [2.8.0 변경점](../release-notes/2.8.0.md)에 정리했습니다.
