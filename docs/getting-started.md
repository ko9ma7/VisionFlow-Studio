# 처음 프로젝트 만들기

1. 기존 Windows 릴리스를 다운로드해 ZIP을 새 폴더에 풉니다. .NET 8 Desktop Runtime x64를 설치하고 `VisionFlowStudio.exe`를 실행합니다.
2. 실행 화면에서 대상 프로그램을 선택합니다. 대상 프로그램의 창이 열려 있는지 확인하세요.
3. **새 작업 만들기**에서 목적을 선택합니다. 이미지 버튼을 찾으려면 이미지 찾기, 텍스트를 읽으려면 OCR 목적을 선택합니다.
4. 생성한 작업의 상세 설정에서 찾을 이미지나 영역을 등록하고 클릭·키 입력 등 수행할 동작을 정합니다.
5. 먼저 관찰 모드에서 탐지 결과와 좌표를 확인합니다. 대상이 맞으면 실제 입력을 허용하고 실행합니다.

일시정지는 현재 동작이 끝나는 안전 경계에서 대기합니다. 중지는 입력을 정리한 후 실행을 종료합니다. 화면의 중지 버튼 또는 활성화한 중지 단축키를 사용할 수 있습니다.

프로젝트를 저장하면 작업 목록과 대상 창 정보가 함께 저장됩니다. 이미지와 모델도 새 PC에 옮겨야 하며 누락된 자산은 실행 전에 확인해야 합니다.

현재 SDK 계약은 초안이며 프로그램에 외부 DLL을 로드하는 기능은 제공하지 않습니다. 새 Smart Action, 변수 및 디버그 기능의 추가 작업은 진행 중입니다.
