# 처음 프로젝트 만들기

## 2.9.0에서 이미지를 찾아 반복 클릭하기

1. 실행 화면에서 자동화할 대상 창을 선택합니다. 대상 버튼이 보이는 상태에서 **이미지 클릭 추가**를 누릅니다.
2. 찾을 버튼의 아이콘이나 글자를 드래그해 **저장**합니다. 버튼이 움직인다면 **캡처한 위치에서만 찾기**를 끕니다.
3. **반복 실행**을 누르면 보이는 그림의 중심을 클릭합니다. 작업을 끝내려면 **중지**를 누릅니다.
4. 실행 전에 위치만 확인하려면 작업 단계를 열어 **찾기만 시험**을 누르세요. 특정 범위에서 미발견이면 **전체 범위로 다시 시험**을 누릅니다. 찾은 위치가 맞으면 **저장**, 원래 설정을 쓰려면 **취소**를 누릅니다.

## 2.8.0 시험판에서 시작하기

1. [설치 안내](install-update.md)에 따라 ZIP을 새 폴더에 풀고 `VisionFlowStudio.exe`를 실행합니다.
2. 대상 창을 선택한 다음 **새 작업 만들기**에서 이미지 찾기 목적을 고릅니다.
3. 작업의 상세 설정에 찾을 그림과 실행할 동작을 지정합니다. 먼저 관찰 모드로 탐지 위치를 확인한 뒤 실행합니다.

일시정지는 현재 동작이 끝나는 안전 경계에서 대기합니다. 중지는 입력을 정리한 후 실행을 종료합니다. 화면의 중지 버튼 또는 활성화한 중지 단축키를 사용할 수 있습니다.

프로젝트를 저장하면 작업 목록과 대상 창 정보가 함께 저장됩니다. 이미지와 모델도 새 PC에 옮겨야 하며 누락된 자산은 실행 전에 확인해야 합니다.

이미지가 보일 때 Enter만 누르거나 클릭 후 문자를 입력하려면 [동작 선택 안내](workflows.md)를 참고하세요.
