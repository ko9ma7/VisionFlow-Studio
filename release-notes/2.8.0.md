# VisionFlow Studio 2.8.0 — 시험판

미서명 검토 후보입니다. [시험판 Release](https://github.com/ko9ma7/VisionFlow-Studio/releases/tag/v2.8.0-preview.20261012)에서 ZIP과 SHA-256을 확인하세요. 자동 업데이트용 서명 릴리스가 아니며 기존 설치를 덮어쓰지 않고 새 폴더에서 실행해야 합니다. Windows x64와 .NET 8 Desktop Runtime이 필요합니다.

- 중단된 업데이트의 복구 화면 정지와 안전한 복원·다시 시작 경로를 개선했습니다.
- 프로그램 실행·종료, 파일·폴더 확인, 창 활성화·이동, 독립 스크롤과 typed 결과를 기존 Workflow에 연결했습니다.
- 자식 Flow의 typed 입출력, 명시적 결과 공개, 취소·실패 시 결과 폐기와 현재 상위 권한 검사를 추가했습니다.
- 선택한 대상의 동작 기록을 편집해 Workflow에 추가하는 Recorder를 구현했습니다. 텍스트 기록은 기본 꺼짐이며 물리 입력·IME·DPI·다양한 앱은 추가 검증이 필요합니다.
- 신뢰한 SDK/API1 확장을 세션에 명시적으로 불러와 Action·Vision·OCR을 실행하고 typed 결과를 연결할 수 있습니다. 같은 PC 권한의 신뢰 코드이며 비신뢰 코드 sandbox나 영구 확장 설치 기능은 아닙니다.
- 프로젝트 형식은 schema22입니다. 이전 프로젝트는 읽을 때 원본을 덮어쓰지 않고 변환하며, 새 형식을 이전 앱에서 열 수는 없습니다. 업그레이드 전에 원본과 백업을 보관하세요.
- 도구의 ‘개인 환경·사용 권한’에서 Windows 사용자별로 기능을 실행 시 확인·항상 허용·차단으로 저장할 수 있습니다. Interception DLL을 직접 선택하고 출처를 확인할 수 있으며 파일이 바뀌면 다시 확인합니다. 드라이버 설치·제품 인증·업데이트 서명은 이 설정으로 대체하지 않습니다.

로컬 19개 검증 범위와 설정 UI를 확인했습니다. Runtime 384개 항목은 동일 소스의 최초 통과 항목과 중단 지점 이후의 분리 실행 결과로 집계했습니다. 실제 대상/실장치·기존 설치 업데이트와 생산 서명·최종 배포 검증은 남아 있습니다.
