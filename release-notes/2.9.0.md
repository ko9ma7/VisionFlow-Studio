# VisionFlow Studio 2.9.0 시험판 변경점

[Windows x64 ZIP 바로 다운로드](https://github.com/ko9ma7/VisionFlow-Studio/releases/download/v2.9.0-preview.20261124/VisionFlow-Studio-v2.9.0-preview-win-x64.zip) · [SHA-256 및 배포 정보](https://github.com/ko9ma7/VisionFlow-Studio/releases/tag/v2.9.0-preview.20261124)

2026년 11월 24일 공개 시험판입니다. 2.8.0에서 사용하던 이미지 작업을 더 적은 단계로 만들고, 미발견 원인을 편집기에서 확인할 수 있습니다. 버전별 실행 파일과 게시 일자는 [GitHub Releases](https://github.com/ko9ma7/VisionFlow-Studio/releases)에서 확인하세요.

- 작업 만들기에서 **이미지 없이 입력**을 고르면 키 누르기·마우스 이동·클릭을 바로 등록합니다. 기본 키는 Enter입니다.
- **이미지를 찾아 동작하기 → 찾은 위치로 이동 후 키 누르기**를 고르면 발견 위치로 이동한 다음 선택한 키를 보냅니다. 숫자 키패드의 숫자와 키보드 윗줄의 숫자를 구별합니다.
- 실행 창을 좁히면 도구 버튼이 다음 줄로 이동합니다.
- **이미지를 찾은 뒤 할 일을 한 화면에서 정합니다.** 키 누르기, 마우스 동작, 여러 동작의 실행 순서를 같은 편집 흐름에서 선택합니다. 키 입력만 선택하면 마우스 동작을 추가하지 않습니다.
- **대상 이미지와 찾을 화면 범위를 구별합니다.** 지정한 범위에서 이미지를 못 찾으면 **전체 범위로 다시 시험**을 누르세요. 게임이나 대상 앱에 입력을 보내지 않고 찾은 위치를 보여줍니다. 발견 후 저장하면 새 범위를 사용합니다. 크기·회전 변화 인식은 시험한 표본 범위의 개선이며 모든 이미지의 검출을 보장하지 않습니다.
- **미니 실행 창의 상태와 제어를 정리했습니다.** 현재 단계와 예정 동작을 보여주며 일시정지 요청, 실제 정지, 재개, 중지 정리를 구분합니다. 편집기로 돌아갔다 와도 실행 상태를 유지합니다.
- **이미지가 사라질 때까지 기다릴 수 있습니다.** 처음 발견한 뒤 새 화면 두 장에서 연속 미검출을 확인해야 다음 단계로 이동합니다. 캡처 실패·잘린 찾기 범위·처음부터 없는 이미지는 성공으로 처리하지 않습니다. 제한시간을 넘기면 기본값에서는 중지하며 이후 입력은 다음 단계에 둡니다.
- **프로젝트 형식이 schema23으로 바뀝니다.** 이전 프로젝트를 읽는 것만으로 원본을 다시 쓰지 않습니다. 새 형식으로 저장한 파일은 이전 프로그램에서 열 수 없으므로 업그레이드 전 원본과 백업을 별도로 보관하세요.

## 지원 범위와 남은 확인

OpenGL DLL 캡처는 프레임 갱신 여부를 제공하지 않아 사라짐 대기에 사용할 수 없습니다. 이 경우 화면 캡처 방식을 자동 또는 다른 방식으로 바꾸세요. 카메라 소스는 이 창 캡처 설정과 별도로 처리합니다.

소유한 시험 창에서 입력/UI 회귀를 확인했으며, 다른 DPI·IME·실장치, 기존 설치 업데이트/복구와 생산 서명·배포 검증은 남아 있습니다. 개인별 사용 권한 설정은 드라이버 설치·제품 인증·업데이트 서명을 대체하지 않습니다. 완료하지 않은 검증을 출하 완료로 표시하지 않습니다.
